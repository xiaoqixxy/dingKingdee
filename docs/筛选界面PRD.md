# 金蝶云星空同步插件 · 筛选界面 PRD

## 1. 字段类型需求表

“基础比较”指等于、不等于、大于、大于等于、小于、小于等于。以下目标操作符为产品建议；当前实现单独列明。

| ID | 字段类型 / 示例 | 目标操作符 | 目标输入控件 | 输入与空值规则 | 当前实现 / 差异 |
| --- | --- | --- | --- | --- | --- |
| F01 | 文本：单据编号、备注 | 等于、不等于、包含、不包含、为空、不为空 | 单行文本框；空值操作显示“无需填写筛选值” | 文本为空指 NULL 或空字符串；空格不算空；包含值不能为空 | 已支持以上操作；目前还展示大小比较，建议隐藏，仅兼容旧配置 |
| F02 | 数字：金额、数量 | 基础比较、为空、不为空 | 数字输入框，允许负数、小数 | 校验有效数字；0 不为空；为空仅指 NULL；不擅自按显示精度舍入 | 操作符已支持，目前使用普通文本框，数字格式校验待完善 |
| F03 | 日期：业务日期、创建时间 | 基础比较、快捷时间范围、为空、不为空 | 日期选择器 + 快捷范围下拉；空值操作不显示日期输入 | 日期合法；快捷范围以查询执行时的日期计算；全天边界见第 3 节 | 已支持日期与快捷范围；当前无时分秒输入，日末边界和时区需完善 |
| F04 | 枚举：单据状态、业务类型 | 等于、不等于、包含于、为空、不为空 | 等于/不等于用单选；包含于用多选 | 显示选项名称，提交原始值；包含于至少选 1 项；空值按源字段类型定义 | 当前统一多选，且仍展示大小比较；等于/不等于单值提交与控件联动待完善 |
| F05 | 布尔：是否启用、是否关闭 | 等于、不等于、为空、不为空 | “是 / 否”单选 | false 不为空；若源字段不可空可隐藏空值操作 | 当前转换为 singleSelect，复用枚举多选；未保留独立布尔筛选类型，需补原始类型语义 |
| F06 | 关联对象：客户、组织、物料 | 按名称或编码文本筛选：等于、不等于、包含、不包含、为空、不为空 | 文本框，字段名明确“名称”或“编码” | 匹配元数据指定的名称/编码属性，不是关联内码；关联属性为空不必然等于未选择关联对象 | 当前按元数据转成 .FName / .FNumber 文本查询；没有远程对象选择器 |
| F07 | 明细字段：明细金额、明细物料名称 | 随实际字段类型 | 随实际字段类型 | 只允许当前选定明细中的字段；显示实体名称前缀，后端转换为实际查询标识 | 已支持字段范围校验和查询标识转换；切换明细会清理失效条件 |
| F08 | 未识别类型 / 内码字段 | 经确认可查询后再开放；默认提供类型提示 | 按确认后的类型 | 不应仅因显示为字符串，就认定源字段也是文本 | 当前未知字段及部分主键回退为 text；源字段类型保留和能力限制待完善 |

## 2. 操作符与后端语义表

下列 F 表示经元数据校验后的实际查询字段，v 表示安全转义后的值。不得直接拼接用户提供的字段表达式。

| 操作符 | 用户含义 | 是否需要值 | 查询语义 | 验收要点 |
| --- | --- | --- | --- | --- |
| 等于 / 不等于 | 精确匹配 / 不等于指定值 | 是 | F = v / F != v | 枚举提交原始值；不等于不会自动匹配 NULL |
| 大于 / 大于等于 / 小于 / 小于等于 | 数值或日期比较 | 是 | F > v / >= / < / <= | 仅在适用类型开放；不得按文本排序替代数字比较 |
| 包含 | 文本中出现输入内容 | 是 | F LIKE '%v%' | 子串匹配；不是枚举多选；大小写遵循源库排序规则 |
| 不包含 | 非 NULL 文本中未出现输入内容 | 是 | F NOT LIKE '%v%' | NULL 不匹配；要包含空值需增加“为空”的 OR 组 |
| 包含于 | 字段值等于任一已选选项 | 是，数组 | F IN (v1, v2, …) | 精确集合匹配，不能理解为文本子串匹配；空选项集应阻止提交 |
| 为空（文本） | 未填写内容 | 否 | (F IS NULL OR F = '') | NULL、空字符串均命中；仅含空格不命中 |
| 不为空（文本） | 已填写内容 | 否 | (F IS NOT NULL AND F <> '') | NULL、空字符串均排除 |
| 为空 / 不为空（数字、日期） | 无值 / 有值 | 否 | F IS NULL / F IS NOT NULL | 0 是有效数字，不能被当作空值 |
| 为空 / 不为空（布尔、枚举） | 源字段无值 / 有值 | 否 | 根据源字段真实类型判断 | 建议布尔只判断 NULL，false 保持有效；当前 singleSelect 复用文本空值语义，需专项修正与联调 |

文本包含中的单引号、%、_、[ 按字面量转义，不能作为用户自定义 SQL 或通配符。当前后端已做上述转义和操作符白名单；按字段类型限制操作符仍需前后端统一完善。

## 3. 日期范围需求表

| 选项 | 产品定义 | 建议验收标准 |
| --- | --- | --- |
| 自定义日期 | 选择某个自然日，配合比较操作符 | 等于某日匹配当天所有时间；不等于排除当天，NULL 单独处理 |
| 近 7 天 | 今天及前 6 天 | 起始日 00:00 ≤ 时间 < 明日 00:00 |
| 近 30 天 | 今天及前 29 天 | 起始日 00:00 ≤ 时间 < 明日 00:00 |
| 本周 | 本周一至本周日，不是截至今天 | 周一 00:00 ≤ 时间 < 下周一 00:00 |
| 本月 | 本月 1 日至月末 | 月初 00:00 ≤ 时间 < 下月初 00:00 |
| 本年 | 1 月 1 日至 12 月 31 日 | 年初 00:00 ≤ 时间 < 次年年初 00:00 |

选择快捷范围后当前保存范围标识并固定为等于，界面隐藏普通操作符；后续同步按执行时的日期重新解析，不保存一次性的固定日期。

## 5. 数据与兼容要求

| 项目 | 约定 |
| --- | --- |
| 条件 | fieldId、operator、value；当前 value 为字符串或字符串数组 |
| 条件组 | filterConditions: [{ conditions: [...] }]；组内 AND，组间 OR |
| 空值操作 | value 约定为空字符串；后端应忽略残留值，不将其拼进查询 |
| 枚举 | 包含于提交数组；建议等于/不等于提交单值，需要补控件与历史配置迁移规则 |
| 快捷日期 | 保存 last_7_days、last_30_days、this_week、this_month、this_year |
| 旧版兼容 | 扁平条件数组仍按 AND 解析；不得自动改变历史逻辑 |
| 明细字段 | 界面使用带实体前缀的字段 ID，后端按元数据映射为 queryKey |
| 空组 | 忽略空组，不产生多余 AND/OR；有效条件校验失败时不能悄悄丢弃条件 |
| 发布顺序 | 先部署支持新操作符的后端，再部署前端 |

## 8. 实施补充（2026-09-18）

本节更新前述评审稿的实施状态：

- 新建文本条件仅展示等于、不等于、包含、不包含及空值操作；数字/日期展示基础比较及空值；枚举增加包含于；布尔不展示大小比较或包含于。
- 数字改用数字输入；枚举等于/不等于使用单选，包含于使用多选；布尔显示是/否选项。元数据缺少枚举选项时不回退自由文本。
- 每行显示类型与输入校验提示，提交拦截无效数字、日期、失效选项、空值输入和不兼容的多值历史条件。空值操作无需值。
- 历史操作符仍保留并标注，不自动更改；旧版单元素数组归一为单值，多元素普通比较要求用户明确修正。
- 日期自定义比较按自然日解释，结束边界使用下一日零点排他；快捷范围按 Asia/Shanghai 每次查询动态计算，文本“this_month”不再误作日期占位符。
- 后端元数据增加布尔和主键筛选类型，布尔 false 与数字 0 保持非空。枚举原始存储类型仍不完整，数字枚举专项类型识别仍待后续完善；未知类型不推测其存储语义。
- 本次没有新增远程对象选择器，没有修改插件最外层尺寸。前述验收中需要正向空值样本或钉钉宿主的项目仍需对应环境验证。
