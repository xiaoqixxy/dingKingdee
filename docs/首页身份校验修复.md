# 首页校验修复

原实现调用 getDataCenters()，获取账套列表不代表当前账套、用户、APP_ID、APP_SECRET 有效，因此会误报连接成功。

现改为使用当前配置新建 SDK 实例并调用 CheckAuthInfo()。只有 ResponseStatus.IsSuccess 明确为 true 才返回 data.verified=true；空响应、失败状态和异常均失败。SDK 8.0.6 使用币别只读查询（预设人民币）检查授权，因此该检查同时依赖相应权限和基础资料，不等同于所有业务表单权限均已具备。

前端仅接受 HTTP 成功、code=0 且 verified=true；对旧版账套列表结果提示更新后端。校验参数直接传入，不修改当前表单状态；校验中禁用重复点击。

验证：前端 23 项测试通过，覆盖旧版假成功、认证失败、身份成功；后端测试覆盖缺失响应、缺失状态、失败和明确成功。本次没有使用真实错误密码执行账号尝试。

部署时先更新后端再更新前端。
