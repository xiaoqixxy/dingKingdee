# 筛选操作符验证（2026-09-18）

新增文本“包含 / 不包含”以及“为空 / 不为空”。组内 AND、组间 OR 的规则不变，保留旧版扁平条件和“包含于”多选匹配。

文本为空：NULL 或空字符串；文本不为空：非 NULL 且非空字符串。数字和日期仅判断 NULL，0 不属于空值。空白字符不视为空字符串。“不包含”按 SQL NOT LIKE 处理，NULL 不匹配；如需包含空值，请另加“为空”的 OR 条件组。包含和不包含按源库排序规则比较大小写。

值中的单引号转义为双单引号，LIKE 中的 %、_、[ 按字面量转义，不允许输入值扩展查询表达式。空值操作忽略旧筛选值。
