# 云星空只读实测记录

测试对象：用户授权账套中的 CRM_Contract。通过项目使用的 K3Cloud SDK 与当前 DetailSyncSupport 查询、转换逻辑验证。未保存、修改、审核或删除业务单据；测试凭证未写入代码文件。

## 根因复现

| 查询字段 | 实际结果 |
| --- | --- |
| FCRMContractEntry_FQty | 金蝶返回字段不存在 |
| FQty（同时查询 FCRMContractEntry_FEntryID） | 最小查询成功 |
| FAuxPropId.FName | 金蝶返回字段不存在 |
| FAUXPROPID__FF100001 | 金蝶返回字段不存在 |
| FAuxPropId.FF100001.FNumber | 查询成功 |

SDK 将业务错误作为单行单列 Map 返回，原查询包装仅记录行数，后续转换才报列数不符。

## 修正

1. 显示/输出 ID 与查询键分离：输出明细 ID 保留实体前缀，查询和条件使用业务字段 Key；仅明细内码及序号使用实体前缀。
2. 辅助属性组合按 FlexFields 展开，以父字段 Key + 子字段 FieldName 构造引用路径，复用既有字段类型转换。
3. 查询结果先识别 ResponseStatus.IsSuccess=false，传递具体错误信息。

## 实测结果

| 场景 | 结果 |
| --- | --- |
| FCreateDate >= 2026-08-16 且 <= 2026-09-14 | 1 行，159 列，转换成功 |
| 去除日期条件的分页样本 | 21 行，每行 159 列 |
| 首行模式 | 检查 20 行，4 条延续明细正确清空表头 |
| 全行模式 | 每条明细保留对应表头，ID 与首行模式一致 |
| 跨页 | 包含上一行的查询与同位置整批转换结果一致 |
| 重试 | 再次查询并转换得到相同结果 |
| 3 行限额 | 仅输出 3 行，hasMore=false，无提示假行 |
| 明细数量 > 0，按数量降序 | 实际查询成功，转换成功 |

仍未验证钉钉宿主落表、空值清除与删除传播。Offset 分页不保证源数据并发变化时的快照一致性。

`output/LiveKingdeeProbe.java` 从标准输入读取连接参数，不保存密钥；需要在后端编译后运行。不要把含密钥的启动命令或实际业务行写入提交文件。
